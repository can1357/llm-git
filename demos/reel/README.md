# Reel
A transparent narrative review strip with deterministic attention signals and an AI reviewer briefing.
Run: `bun install && bun start`
AI uses Haiku via localhost:4000, switching to cached 8-way file map-reduce above 25 KB / 12 files; set `REEL_AI=0` to disable.
Keys: `J/K` or `↑/↓` navigate · `←/→` decide · `⏎` toggles diff · `A` accepts ezpz · `U` undoes.
